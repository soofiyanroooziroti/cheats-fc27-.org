# cheats-fc27-.org

Astro static marketing site for **FC27 Cheats** ([cheatsfc27.com](https://cheatsfc27.com)): products, blog, forum, i18n, and checkout via `/go/` hops.

## Commands

```bash
npm.cmd install
npm.cmd run dev          # local dev
npm.cmd run build        # production build
npm.cmd run qa           # build:i18n-test + check:seo + verify
npm.cmd run translate    # Gemini i18n (requires .env, not committed)
```

Site playbook: see `../astro-marketing-site-playbook.md` in the parent `Websites` folder.
